Odoo Data Cleaner Pro (Odoo 19)
🧾 Overview

Odoo Data Cleaner Pro is a powerful and safe utility module designed to help administrators clean and reset demo or test data efficiently within Odoo.

Using a simple and intuitive wizard interface, users can selectively remove transactional and operational data such as Sales, Purchases, Inventory Operations, Projects, and Contacts — all in just a few clicks.

This module is especially useful for development, testing, training environments, and pre-go-live database preparation.

🚀 Key Features
✔ Selective Data Cleanup

Easily choose which type of data to clean:

Sales Orders & Deliveries
Purchase Orders & Receipts
Inventory Operations
Projects & Tasks
Customers & Vendors
✔ One-Click Full Cleanup

Enable the “All Data” option to clean multiple data categories in a single action — ideal for resetting demo or staging environments.

✔ User-Friendly Wizard

A clean and intuitive wizard interface allows administrators to:

Select data categories
Execute cleanup safely
Work directly inside Odoo without technical complexity
✔ Safe & Controlled Execution
Restricted to system administrators only
Built using Odoo ORM standards
Designed to avoid system-critical records
🎯 Use Cases

This module is ideal for:

Development environments
Testing and QA databases
Training/demo systems
Preparing a clean database before go-live
⚠️ Important Notice

This module performs permanent data cleanup operations.

👉 It is strongly recommended to:

Use it only in test or staging environments
Take a full database backup before execution
🛠 Installation
Step 1: Install the Module
Download the module from the Odoo Apps Store
Copy the module folder into your Odoo addons directory
Restart your Odoo server
Step 2: Activate Developer Mode (if needed)
Go to Settings → Activate Developer Mode
Step 3: Install from Apps
Open the Apps menu
Search for Odoo Data Cleaner Pro
Click Install
⚙️ How to Use
Navigate to the module from the menu
Open the Data Cleanup Wizard
Select the data categories you want to clean
Click Clear Selected Data
🔐 Access Rights

Only users with Administrator (Settings) access can execute cleanup operations.

📦 Compatibility
Odoo 19 Community
Fully compatible with standard Odoo modules
