Odoo Data Cleaner Pro (Odoo 19)

Save hours of manual cleanup — reset your Odoo database instantly and safely.

Overview

Odoo Data Cleaner Pro is a powerful utility designed to quickly remove unwanted or test data from your Odoo system using a simple and intuitive wizard.

Clean Sales, Purchases, Inventory, Projects, Customers, Vendors, and Accounting data with full control — or reset everything using the All Data option in one click.

What You Can Clean

  • Sales Orders & Transfers
  • Purchase Orders & Transfers
  • Inventory Operations
  • Projects, Tasks & Timesheets
  • Customers & Vendors
  • Invoices, Payments & Journal Entries
  • Manufacturing (BOM & Orders)

Key Features

Easy Data Cleanup

Remove unwanted records using a simple wizard interface.

One-Click Full Reset

Enable "All Data" to clean everything instantly.

Selective Control

Choose exactly which modules to clean.

How It Works

Select data categories -> Click Clear Data -> Done. Clear Data → Done.

Setup & Usage

Important Notice

IMPORTANT: This module permanently deletes data. Use only in test or staging environments.
Always take a backup before use.

Installation

  1. Copy the module into your Odoo addons folder
  2. Restart Odoo server
  3. Go to Apps → Search for Odoo Data Cleaner Pro
  4. Click Install
